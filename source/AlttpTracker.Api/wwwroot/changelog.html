ChangelogALTTP Co-op Tracker

Beta 1 — 11 September 2026

  • The first public build. A shared board for co-op runs: the 30 main items, the dungeon keys, and all 216 checks, live for everyone in the room.
  • Rooms are kept, so closing the tab and coming back later picks the run up where it was. A room code is three words — generate one on the home page and share the link.
  • Progressive items (Sword, Shield, Mail, Gloves, Bow, Bottle) hold several locations and show a found/total count. A check only ever holds one item, so nobody's note is overwritten.
  • Real item sprites on the tiles, with region filters and a switch to hide checks already recorded.
  • The whole item tile is the button now. Click anywhere on an item to arm it — the little pencil in the corner is gone. The × next to a recorded location still clears just that location.
  • Click in either order. Item then check, as before, or check then item — both record the same thing. The bar at the bottom says which half is still to be clicked, and Esc cancels either.
  • The "Filter checks…" box is gone. Nobody stops to type mid-run; the region chips and the hide switch do the job with one hand still on the controller.
  • Open source. Report anything wrong at github.com/AndyMcKenna/AlttprCoopTracker.
