A Link to the PastCo-op Tracker

A shared board for co-op runs. One player finds an item, records where it came from, and everyone else sees it straight away.

You will get a room code to share. Anyone who opens it joins the same board.

How it works

  1. Click an item to arm it.
  2. Click the check where you found it — all 216 are there. (Check first, then item, works too.)
  3. The location is recorded next to the item for everyone in the room.

Rooms are kept, so closing the tab and coming back later picks the run up where it was. Progressive items hold several locations, and a check only ever holds one item, so nobody overwrites anyone else's note.

Found a problem?

The tracker is open source and in beta. If a check is out of order, an icon is wrong, or something just breaks, open an issue on GitHub and say what you were doing when it happened. The code is there too, if you would rather send a fix.
